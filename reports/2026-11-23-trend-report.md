## Actionable insight
The account-isolation bug class is the one thing in this week's list that maps onto a defect we can ship in a day. `tiny-skill-lint` and the skill loader both key on filesystem path, and the 2026-11-20 baseline-fingerprint incident was *exactly* this shape: a hash generated at one scope silently failed to match at another because the scope, not the file, was the identity. Pinky solved the agent-side version by making the gateway the identity boundary. The cheap version for us: any cached result — baseline fingerprint, semantic cache key, memo entry — should carry the **credential/scope it was computed under** as part of the key, so a cross-scope read is a cache miss and not a stale hit. Start with `tiny-semantic-cache` and the baseline loader, and write the failing test first (same key, two scopes, must not collide).
