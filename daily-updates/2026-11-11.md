## TL;DR

1. **`bytedance/deer-flow` 85,247★ / 12,006 forks, MIT, v2.2.0 (2026-11-04),
   pushed 2026-11-11 13:00Z, 1,089 open issues.** The long-horizon SuperAgent
   harness (sandboxes, memory, tools, skills, subagents, message gateway)
   merged **`feat(approvals): add Ask, Auto and Full tool permission modes`
   (#8033)** today. The commit body is the interesting part: it lists
   `human-in-the-loop approval for high-risk tool calls`, `guard approval
   pause recovery`, and "address approval review findings" — i.e. the
   per-call consent model that agent stacks have been describing in prose is
   now an enumerated, testable enum (`Ask` / `Auto` / `Full`).
   **Note the fork-to-star ratio: 12,006 forks against 85,247 stars is 14%.**
   For comparison `modelcontextprotocol/servers` sits at 91,923★ with a much
   flatter ratio. A high fork ratio on a harness usually means people are
   copying it to run it, which is a better signal than stars alone.

2. **`Ask`/`Auto`/`Full` is the right shape and the wrong shape at once.**
   Right: three modes is the minimum that expresses (a) every tool confirmed,
   (b) safe-by-policy, (c) unattended. Wrong: "Auto" is doing an enormous
   amount of work in one word — it is policy, and policy is where agent stacks
   break in production. The thing to watch is whether `Auto` gets a rule
   surface or stays a boolean with a nicer name.

3. **`hashgraph-online/hol-guard` 1,088★, 93 open issues, pushed today.** The
   agent firewall from yesterday's report is holding its cadence one day
   later: still the only agent-security project with a checkable install path
   and a release history. Our `tiny-mcp-audit` still has **no PyPI package**,
   so its CVE-2026-103572 rules (MCP075–MCP077) remain unreachable by
   `pip install`. Named again because "named in a report" is not a
   shipped workaround.

4. **`jlowin/fastmcp` v4.1.8 and v4.2.0a4 both dated 2026-11-10, 238 open
   issues.** No new release overnight. `modelcontextprotocol/servers` 91,923★,
   pushed today but no issue churn (14 open) — a reference repo that is
   quiet, not a project in motion.

5. **Fleet result: 85 of 93 package names are free, and the one published
   name of ours is six minor versions behind.** `pysnapdb` on PyPI is 0.14.0;
   the repo shipped 0.18.1 today. The install path is the only line of a
   README a user executes, and it is the line nothing checks. Report and the
   stdlib-only audit script are in `reports/2026-11-11-pypi-name-census.md`.

6. **Key signal for us:** the agent-harness feature that shipped today
   (`Ask`/`Auto`/`Full`) is the same distinction `tiny-mcp-audit` should be
   expressing in lint output: *does this tool need a human in the loop?* A
   rule that flags "this MCP tool mutates host state and declares no consent
   requirement" is more useful than another regex over secrets, and it is the
   gap `hol-guard` cannot fill because it inspects packages, not declarations.

## The day's reusable rule

Four defects, one sentence: **a test that checks the thing you built is not
the same as a test that checks the thing you ship.** The tarball, the suite
as run, and the deployed artifact are all one step removed from the
checkout — and each of the four bugs lived exactly in that gap.
