### The one that matters: OpenSandbox (17.2k★, Apache-2.0, AAIF project)

Isolated sandbox runtime for agents: Firecracker creation **64 ms P50 /
125.4 ms P99 at 10 concurrent**, pause/resume with memory+disk preserved,
per-sandbox **egress policy**, an **ingress gateway**, and a **Credential
Vault** that injects outbound credentials so sandbox workloads never hold
them. Ships Python/Java/TS/C#/Go SDKs, an `osb` CLI, and an MCP server.
Docker locally, Kubernetes via an operator. 187 open issues, and **zero
`good first issue` labels** (`gh search issues` returned `[]`) — so it is a
learning target, not a contribution target this week.

Relevance: the Credential Vault is exactly the shape of the problem in
AGENTS.md "a corpus with author attribution survives string matching" — the
agent never sees the secret, only the injected header. Our own git-credential
handling is the same idea with none of the isolation.
