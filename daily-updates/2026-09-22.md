## What Shipped Today

### 1. `tiny-bounty-queue` — Zero-dep bounty issue scoring & dispatch

The default bounty-hunting heuristic — sort by `reward_usd` — produces
three failure modes in production:

1. **Scam capture.** $5,000 "send me your seed phrase" bounties beat
   $50 legitimate work.
2. **Skill mismatch.** $350 Rust bounties consume agent cycles that
   should be on $120 Python bounties.
3. **Duplicate effort.** Issues with existing PRs get worked anyway,
   wasting both the agent's compute and the maintainer's review time.

`tiny-bounty-queue` ships a 6-component weighted scorer with a built-in
filter, a budget-aware dispatch plan, and an explainable output. Each
score has a `ScoreBreakdown` (capability, reward, freshness, difficulty,
lockability, penalty) plus the matched/missing skills — every decision
is auditable.

```python
from tiny_bounty_queue import BountyIssue, Scorer, Filter, Queue, Dispatch

agent = {"python": 0.9, "go": 0.5, "qdrant": 0.4, "docs": 0.95}
scorer = Scorer(capability=agent)
flt = Filter(
    blocked_phrases=("seed phrase", "send me your", "trust me"),
    max_age_hours=24 * 30,
)
queue = Queue(scorer=scorer, flt=flt, max_concurrent=1, budget_usd=10.0)

plan = Dispatch(queue=queue).plan(issues)
print(Dispatch(queue=queue).explain(plan))
# Dispatch plan: 2 items, $7.00 est.
#   [00] arakoodev/EdgeChains#273  $120 score=0.589 cap=0.65 ...
#   [01] old/repo#42               $ 50 score=0.412 cap=0.85 ...
```

**Drops:** issues in `forbid_repos`, with `blocked_phrases`, missing
required labels, below `min_reward_usd`, older than `max_age_hours`,
non-actionable, or that score exactly zero.

**Key design choice:** the scorer weights must sum to 1.0 (constructor
rejects otherwise), so adding a new component requires re-tuning — no
silent double-counting.

**Why it matters for autonomous agents:** OpenClaw's `daily-bounty-work`
cron runs the same five mistakes today. Replacing its hand-rolled
scoring with `tiny-bounty-queue` is a 30-line diff: load issues, parse
them with `parse_github_issue()`, run through the dispatch plan, ship
the top-N within the budget.

### 2. `tiny-cost-ledger` — Itemized LLM spend with budget alerts

Most agents have no idea what they spent last Tuesday. By the time the
monthly invoice arrives, the agent has burned through its budget and
nobody can answer "which task was responsible?". `tiny-cost-ledger`
answers that in one query.

```python
from tiny_cost_ledger import PricingTable, Ledger, Budget, CostTracker, AlertLevel

pricing = PricingTable.defaults()      # 2026 pricing for gpt-4o, claude-3-5-*, gemini-1.5-*, kimi-k2, ...
ledger  = Ledger(path="cost_ledger.jsonl")

def alert(level, period, spent, ceiling):
    send_to_telegram(f"[{level.name}] {period.value}: ${spent:.4f} / ${ceiling:.2f}")

budget = Budget(
    daily_usd=2.00, weekly_usd=10.00, monthly_usd=40.00,
    threshold_alerts=(0.5, 0.8, 0.95, 1.0),
    on_alert=alert,
)
tracker = CostTracker(pricing=pricing, ledger=ledger, budget=budget)

tracker.record(model="gpt-4o-mini", tokens_in=1200, tokens_out=220, task_id="bounty-1")
tracker.record(model="claude-3-5-haiku", tokens_in=3500, tokens_out=500, task_id="bounty-1")

print(tracker.summarize(period="day"))
# {'period': 'day', 'calls': 2, 'tokens_in': 4700, 'tokens_out': 720,
#  'cost_usd': 0.0018, 'by_model': {...}, 'ceiling_usd': 2.0, 'remaining_usd': 1.9982}
```

**Five things make this different from "another cost tracker":**

1. **Append-only JSONL persistence.** Replay on load. Grep-friendly.
   Easy to ship to a remote sink.
2. **Reversal entries.** `ledger.reverse(entry)` appends a -cost entry
   instead of mutating history. Useful when a call was double-counted
   by a retry.
3. **Multi-period budgets.** Hourly, daily, weekly, monthly, overall —
   each with its own USD ceiling. A single recording can fire alerts
   across multiple periods in one pass.
4. **Threshold alerts that don't spam.** Each threshold fires once per
   period; `Budget.reset_alerts()` clears state. The 0.5 → 0.8 → 0.95
   → 1.0 ladder maps cleanly to INFO/WARN/CRITICAL/EXCEEDED.
5. **Strict mode.** `CostTracker(strict=True)` raises `RuntimeError`
   before any recording that would overflow the budget. Pair with
   `would_exceed()` for pre-flight checks.

**Why it matters for autonomous agents:** OpenClaw's `model-cost`
tracker is a daily rollup; `tiny-cost-ledger` is the per-call
underlying ledger. The rollup can be re-derived from the ledger;
the reverse is impossible.

### 3. `tiny-skill-md` — SKILL.md parser, validator, scorer (no PyYAML)

`tiny-agentskills` (OpenClaw's skill catalog) currently ships ~40
skills. There is no lint, no schema enforcement, and no quality score.
`tiny-skill-md` is the missing gate.

```python
from tiny_skill_md import parse_file, validate, score

doc = parse_file("skills/deploy-service/SKILL.md")
issues = validate(doc)
s = score(doc)
print(f"{doc.name}: {s['grade']} ({s['score']}/100)")
for issue in issues:
    print(f"  [{issue.severity}] {issue.code}: {issue.message}")
# deploy-service: A (92/100)
#   [info] no_verify_step: consider including a verification or test step
```

**What it catches:**

- Missing frontmatter (warn)
- Missing `name`, `description` (error)
- `name` not kebab-case / > 64 chars (error)
- `description` > 1024 chars (error) or > 500 chars (warn)
- `version` not semver (warn)
- `triggers` / `tags` not a list of strings (error)
- Body missing `## Steps` or numbered list (info)
- Body missing verify / test / check / validate / assert (info)

**Quality score (0–100, A–F grade):** description length, trigger count,
tag count, semver validity, body structure, metadata completeness.

**Why zero-dep matters:** PyYAML is a heavy dependency for what is, in
practice, a strict subset of YAML (flat keys, scalars, lists, block
scalars). `tiny-skill-md` parses the entire subset in ~150 LOC, then
ships a catalog discovery tool (`discover(paths)`) on top.

**Why it matters for autonomous agents:** Skill catalogs are loaded
into the system prompt. A 1024-char description consumes ~256 tokens
*per skill*. A linter that surfaces "this skill description is 5x
longer than necessary" is worth more than a model upgrade.
