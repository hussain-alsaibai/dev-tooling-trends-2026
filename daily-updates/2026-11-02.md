## The durable lesson

**A doc test is the cheapest guard against a README lying.**

`fast-cache` now ships `tests/test_readme_consistency.py`, which:

- parses every `Cache(...)` call in the README and checks each keyword argument
  against `inspect.signature(Cache.__init__)`;
- resolves every `from X import Y` in the README against a real module and a real
  attribute;
- asserts the removed sections stay removed.

Run against the old README it produces three failures. Run against the current
one it passes. The same shape is worth copying to any repo whose README shows
constructor calls.

**A second rule: a changelog entry is not evidence.**

`fast-cache` v0.8.0 shipped a CHANGELOG entry stating that the README no longer
advertised `swr_ttl`, `namespace=` or a Redis adapter, and that the performance
table had been replaced with real benchmark output. The changelog was correct
about the *intent* and wrong about the *artifact* — the README on `main` still
contained all three. A claim about a file has to be checked against the file.
