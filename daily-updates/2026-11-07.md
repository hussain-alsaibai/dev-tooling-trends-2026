# Daily Update — November 7, 2026

> **Theme: the tool that ships with the agent wins — and the newest 10k+ star
> repos this week are almost all agent skills, not binaries.**

## TL;DR

1. **Agent skills are now the fastest-growing repo shape.** Created 2026-10-29,
   `heydamir/unslop` reached **10.8k stars / 593 forks in 8 days** with a
   single Claude/Codex skill that strips "AI-looking" UI (purple gradients,
   glows, emoji labels) and redlines it pass by pass. No runtime, no CLI —
   install is `cp -r skills/unslop ~/.claude/skills/`. Its 6 open issues
   (#17-#22) are all *portability* requests: Antigravity install docs,
   Playwright lazy-scroll before snapshot, `.story-frames` cleanup on failure.
   Signal: distribution is `cp -r`, and the backlog is "make it work on the
   next harness", not "add features".

2. **`storytold/craft-anything` — 18.4k stars in 7 days** (created 2026-10-31,
   Rust, MIT/Apache-2.0, 213 open issues). Points a clean-room engine at any
   site/app/game, has a coding agent rebuild it, then diffs the result against
   the original. First trending tool we've seen whose quality gate is
   *compare-against-reference* rather than a test suite.

3. **`interplains/Zero-Breach-Toolkit` — 4.5k stars, weaves slower**
   (created 2026-10-25, 4.5k/477, pushed 11-05). Open-source Pegasus/Predator/
   Candiru spyware-trace checker, Python. Only 7 open issues. Worth watching
   as the credibility signal for security tooling that does not promise detection.

4. **MCP keeps moving *device*-ward, not server-ward.** New this week:
   `phone-harness/mcp` (732★) and `JosssphZhou/poki` (428★) both expose real
   iPhones/Androids to agents over MCP; `qybaihe/bla` (2.6k★, created 10-25)
   is an adversarial shield for blind agents. Note what is *absent*: no
   consumer-contract or schema-drift tooling shipped. Our `tiny-mcp-client`
   `tiny_mcp_contract` remains the only implementation we know of.

5. **Bounties: the only volume is a non-cash token pool.**
   `Scottcjn/rustchain-bounties` (288★/431 forks, 910 open issues, 332 closed)
   pays RTC, and its own README says "**RTC is an experimental token with no
   cash-out**". The work is real and well-scoped (5-35 RTC: Click `CliRunner`
   tests for a zero-test Python SDK CLI, `/health` body validation, vintage
   miner ports) — but the payout is merge credit in a token nobody can redeem.
   Treat as portfolio work, not income. Cash bounties still thin:
   `zhangjiayang6835-cyber/bounty-plaza` reposts the same `$750` tt-metal
   template against a 13-star repo.

6. **One we use moved:** `anthropics/skills` (188k★) shipped
   *"Move Office skills to the Apache 2.0 license"* (11-06) and, on 10-28,
   updated `mcp-builder` to teach **MCP TypeScript SDK v2**. The licensing
   change is the one to check against our vendored skill copies.
