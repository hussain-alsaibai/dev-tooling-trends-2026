# Daily Update — November 10, 2026

> **Theme: an agent antivirus with real packaging appeared, and the
> canonicalisation fix shipped — but not to PyPI.**

## TL;DR

1. **`hashgraph-online/hol-guard` — 1,081★, 259 forks, Apache-2.0, on PyPI
   (`hol-guard` 3.59.0, plus `plugin-scanner`).** Open-source
   "antivirus and firewall for AI agents": blocks risky tools, secret
   access, prompt injection, malicious packages, MCP servers and plugins.
   Created 2026-03-28, pushed within the hour, 98 open issues, ships
   pre-commit hooks + a GitHub Action + flake/trivy/gitleaks configs. This
   is the first agent-security project of the year with package reality
   behind the README — unlike the SkillSpector-style scoring tools, the
   install path and release cadence are checkable, and the version is
   published where a user can actually get it.
   Model for us: `tiny-mcp-audit` should ship the same three surfaces
   (pre-commit hook, Action, CLI) rather than only a CLI.

2. **`tiny-mcp-audit` 0.3.0 landed the CVE-2026-103572 family as
   MCP075–MCP077** (`9ac9233`, README + CHANGELOG, origin/main current).
   MCP075 (high) catches a path argument that reaches a host config or
   credential dir through a non-canonical spelling — trailing dot, case
   variant, `%2e`, `::$DATA`, 8.3. MCP076 names the path directly or walks
   to it; MCP077 flags non-canonical form. **But PyPI has no
   `tiny-mcp-audit` package at all** (`/pypi/tiny-mcp-audit/json` → Not
   Found), so `pip install tiny-mcp-audit` — the command our README and the
   yesterday's plan both assume — installs nothing. The rule exists and is
   unreachable.

3. **FastMCP shipped two releases hours ago: 4.1.7 and 4.2.0a4.** 4.1.7
   backports 42 fixes and is security-relevant: repeated `iss` collapsed in
   the client redirect, redirect URI validation gap for raw strings, and
   hard requirements on patched `joserfc` and `Authlib`. 4.2.0a4 is titled
   "Skills to Pay the Bills" — the Skills primitive is arriving in the
   MCP server framework itself, which changes what a "server" bundles.

4. **`jlowin/fastmcp` 28.4k★ and `modelcontextprotocol/servers` 91.9k★
   (v2.3.0, 2026-11-04)** — the reference servers have moved to a v2 line
   with its own release channel. `vercel-labs/agent-desktop` 20.6k★ hit
   88.6% of its stars in the last ten days and pushed within the hour;
   `D4Vinci/Scrapling` 100.7k★ is MCP-native scraping.

6. **The one bounty worth reading: `hanzoai/ai` #136–#138, "[QA Bounty]
   [P0]"** — 21★, 10 forks, real repo since 2025-06, pushed 2026-11-09.
   Issues are specific and testable: cross-model API compatibility
   (identical OpenAI `/v1/chat/completions` and Anthropic `/v1/messages`

   verify before claiming. The *shape* is the interesting part: it is
   exactly the conformance surface `tiny-llm-router` should own.
