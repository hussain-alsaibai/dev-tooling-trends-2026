2. **MCP is now remote-first, and the registry is the distribution channel.**
   - Registry census (2026-10-14): **43,012 active servers**, 150,595 published versions.
   - **64% have a remote URL**; among servers first published in Oct 2026 it is **78%**, up from 27% in Dec 2025. SSE-only is down to 2.6%.
   - Security reality: **52% of sampled remote servers answer the handshake with no credentials**, 39% return 401 (85% of those advertising OAuth metadata), **7% are dead at the URL they list**, 23% of versioned handshakes report a pre-2025-11-25 spec revision.
   - TypeScript SDK: **273.3M downloads in 30 days, 8.7x the year-earlier window.**
   - New MCP **roadmap** published (five priority areas): agentic messaging primitives (server-initiated events, webhooks/channels instead of polling), agent identity, governance, enterprise readiness, transport evolution.
   - The 2026-07-28 spec removed the `initialize` handshake; `server/discover` is now the capability probe. Only 1 of 500 probed servers actually refused the old handshake.

3. **MCP SDK advisories from 2026-10-15 are unclaimed.**
   - **GHSA-jm63-cq47-j5jp** (high) — shared transport or server instances delivered one HTTP client's messages to another. TS SDK >= 2.0.0 < 2.3.0.
   - **GHSA-46jr-4wx8-v453** (high) — one request within the default size limit could exhaust server memory during validation. TS SDK >= 1.3.0 < 1.32.0.
   - **GHSA-rvq5-wwqv-78pq** (medium) — server bearer auth accepted tokens issued for another resource server. TS SDK >= 1.6.0 < 1.32.0.
   - Python SDK: **GHSA-84m7-p3x7-pcfv** (high) — streamable HTTP sessions never reclaimed by default and kept their initialize payloads; **GHSA-w4fh-qvv9-3v23** — token audience not bound.
   - Fixed in TS SDK **1.32.0+** and **2.3.0+**; Python `mcp` is at **2.3.0**.

   - `context-bridge` v0.2.1 already implements `server/discover` for the 2026-07-28 spec but is **not in the official registry** (search for `context-bridge` and `hussain-alsaibai` returns nothing; two unrelated projects own the name). Registry is where 43k servers are discovered, and 78% of new entries are remote — a hosted `context-bridge` endpoint plus `server.json` is the missing half of the product. Two blockers to fix first: the npm name `context-bridge` is **squatted by a third party**, and `mcp-publisher` is a pre-built binary / Homebrew install, not an npm package.
